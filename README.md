# SpiralSeal

A simple SpiralSeal Module for Multi factor authentication.

With SpiralSeal, you get a lightweight tool that stays out of your way.

**What you get**

- A simple SpiralSeal Module for Multi factor authentication

## Key Features

- A simple SpiralSeal Module for Multi factor authentication

## Technology Stack

- javascript
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/SpiralSeal.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

SpiralSeal is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
